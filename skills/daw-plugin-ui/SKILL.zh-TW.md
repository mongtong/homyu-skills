# DAW 外掛 UI 規範（繁體中文版）

作者：Hom Yu。在開發 HY Humanizer 的過程中整理。英文版 `SKILL.md` 為 agent 實際載入的版本，本檔為對照翻譯。

音樂人在前十秒就會對外掛介面下判斷，而且當下耳朵在音樂上、一隻手在滑鼠上。介面必須不用閱讀就能操作、絕不能打斷聲音，而且要跟 DAW 裡其他外掛的行為一致。新意放在聲音上，不要放在控制項上。

## 0. 動手前的三個問題

1. **跑在哪裡？** DAW 裡的外掛視窗（固定的小視窗、外面是深色的 host 介面）、獨立程式，還是拿來做聆聽測試的網頁原型。三者的控制慣例相同，只有外框不同。
2. **哪些是邊聽邊調、哪些是設定一次就不動？** 邊聽邊調的放主畫面、用大旋鈕或推桿。設定一次的（延遲模式、輸出路由、偵測靈敏度）放次要列或「進階」區。
3. **第一眼一定要看到什麼？** 通常是：它有沒有在作用（電表／活動指示）、作用多少（主要的量旋鈕）。把這個放在視覺中心。

## 1. 控制項慣例（不可違背）

這些與 Ableton Live、Logic、FabFilter、Valhalla 等一致。不照做會被當成 bug。

| 控制項 | 行為 |
|---|---|
| 旋鈕 | 垂直拖曳（或垂直＋水平）。全程約 150–200 px。滑鼠滾輪可調。 |
| 推桿 | 垂直拖曳；dB 刻度、標出 0 dB、unity 卡點；範圍 -∞ 到 +6（或 +12）dB。 |
| 微調 | 拖曳時按住 Shift（或 Cmd/Ctrl）= 10 倍精細。 |
| 回到預設值 | 雙擊（Alt/Option 點擊亦可）。每個連續控制項都要有預設值。 |
| 數值輸入 | 點或雙擊數值可以打字；Enter 確認、Esc 取消。 |
| 數值顯示 | 永遠可見且帶單位：`24 ms`、`-6.0 dB`、`+4 c`、`50 %`。最多一位小數。 |
| Pan | 水平滑桿或旋鈕，中央卡點，顯示 `C` / `L35` / `R20`。 |
| 開關 | 用填色而非只用顏色表示狀態。 |
| 分段選擇 | 2–4 個互斥模式（Mono/Stereo、Mix/Live）用分段按鈕。5 個以上才用下拉選單。 |
| Bypass | 永遠可用；必須尊重 host 的 bypass。A/B 比較放在旁邊。 |

網頁原型的鍵盤：空白鍵播放／停止、數字鍵 solo 各頻道、`M` 取消全部 solo、`B` 或 `A` bypass／A-B、`R` 隨機／換 seed、`?` 顯示快捷鍵。文字或數字欄位有焦點時絕不攔截按鍵。

滑鼠操作絕不能造成 host 層級的問題：沒有原生 alert、播放中沒有 modal 對話框、視窗失焦後不能還抓著游標。

## 2. 聲音回饋也是 UI 的一部分

- 所有重要的輸出路徑都要有**電表**：peak 加 hold（約 1 秒衰減）、clip 指示要鎖住直到點擊或約 2 秒。刻度 -48..0 dBFS（推桿則 -60..+6）。綠 → 琥珀（-12）→ 紅（-1）。要有 peak-hold 線，不只是一條 bar。
- 分析驅動的功能要有**活動指示**（偵測到起音、鎖到音高、gate 打開），讓使用者分得出「它有聽到我」和「它壞了」。
- 外掛有回報任何**延遲**時要用數字顯示（`Latency 48 ms · host 已補償`）。會改變延遲的模式要在選之前就說明。
- **音量對齊的 A/B**：比較處理前後時，對齊 RMS 或提供「match」按鈕。比較大聲的永遠聽起來比較好，會毀掉比較。
- **音訊執行緒上不做任何 UI 的事。** 電表用 timer 以 30–60 fps 讀 atomic 或 lock-free FIFO。音訊 callback 裡絕不配置記憶體、上鎖、寫 log 或碰 GUI。（JUCE：`Timer` + `std::atomic<float>` 或 `AbstractFifo`；網頁：`AnalyserNode`，或 AudioWorklet 傳訊息到主執行緒。）

## 3. Seed、隨機與可重現性

很多音樂工具有隨機性（humanize、doubler、生成式）。這樣呈現：

- 一個可見的 **Seed** 數字欄位（0–9999 比較友善），加上 ◀ ▶ 步進和 🎲 **新 seed** 按鈕。同一個 seed 永遠給同一個結果，存檔重開也一樣。
- 骰子用領域語言命名（「換一批樂手」、「重抽」），不要只寫「Randomize」。
- 一列**最愛**，可以把喜歡的 seed 釘起來，顯示 seed 和當時聽到的關鍵設定。
- 換 seed 要平滑過渡或交叉淡化，絕不能爆音或停止播放。
- 把「**多少**隨機」（量的旋鈕）和「**哪一組**隨機」（seed）分開。量的旋鈕絕不能重新洗牌。

## 4. 外掛視窗排版

- 固定比例，效果器預設約 640×400 到 900×520 px；可以的話支援等比縮放。在 1080p 筆電 100% 縮放下一切都要讀得到。
- **Header 列**：名稱、預設值瀏覽（上一個／下一個／選單／儲存）、A/B、bypass、有的話 seed。設定（齒輪）放最右。
- **主區**：決定聲音的 3–6 個控制項，排成一到兩列旋鈕，最大的＝最重要的。依功能分組（「樂手」、「時間」、「輸出」），每組上方放 12 px、加字距的標題。
- **Footer**：電表、延遲、輸出模式、小小的版本號。
- 間距階層 4/8/12/16/24。旋鈕的標籤在上、數值在下。標題 11–12 px 大寫、數值 12–13 px 等寬字、內文 13–14 px。
- 任何控制項最小點擊面積 28×28 px，演奏中會用到的 36 px。

聆聽測試用的網頁原型另外要有：讓使用者放自己檔案的拖放區、帶事件／標記疊層的波形、每條渲染路徑一條的 mixer（推桿＋pan＋M/S，master 帶 limiter），以及 DSP 有可量化主張時的指標面板。匯出 DAW 開得起來的格式（24-bit WAV；多檔打包 zip）。

## 5. 視覺語言

- **預設深色**：DAW 都是深色，亮色外掛視窗會刺眼。背景亮度約 #15–#20，面板亮一階，一個強調色代表「數值／啟用」，一個警告色。數值的文字對比 ≥ 4.5:1，標題 ≥ 3:1。
- 強調色用在旋鈕和推桿**已填滿**的部分，讓設定值隔著房間也看得到。
- 避免擬真的 skeuomorphism，也避免純扁平灰。微微內凹的軌道加一個清晰的亮色拇指就夠了。
- 字型：產品名用一款窄體展示字、標籤用一款人文無襯線、數字用一款等寬字。字型本地載入或用允許的 CDN；絕不讓字型擋住首次繪製。
- 頻道／take 的顏色在 mixer、波形疊層和表格間保持一致（Take 2 到處都是同一個色相）。
- 圖示：SVG、16–20 px、一定有 tooltip 或標籤。正式外掛 UI 不用表情符號（原型可以）。
- 動畫只用在狀態改變（電表、載入預設值時數值的滑動，120–180 ms）。沒有裝飾性動態；尊重 `prefers-reduced-motion`。

## 6. 狀態與預設值

- 使用者能碰的每一樣都是 host 參數（可自動化）或存在外掛狀態裡。Seed、模式開關、mixer 音量都包含。
- 預設值 = 全部參數 + seed。載入時數值滑動過去，不能爆音。
- 破壞性操作（全部重設、全部隨機）要有 undo。
- 某個控制項的效果需要離線重新分析時（靈敏度、模型選擇），在標題說明，並在使用者放開後自動重跑；新結果好之前繼續播舊的。

## 7. 檢查清單（任何外掛 UI 出貨前跑一遍）

1. 每個連續控制項：拖曳可用、Shift 微調可用、雙擊重設、數值帶單位。
2. UI 裡沒有任何東西會讓聲音出錯（編輯器開著和關著都量過）。
3. 訊號進來 50 ms 內電表有反應；clip 鎖定正常。
4. Bypass 和 A/B 一鍵可達，音量可比較。
5. 同一個 seed／預設值 → 存檔、關閉、重開後聲音一模一樣。
6. 13 吋筆電 100% 縮放下可讀；繁體中文或德文標籤沒有被截斷。
7. 鍵盤焦點不會被困住；外掛沒用到的 host 快捷鍵（空白鍵、Cmd-Z）要能傳到 DAW。
8. 視窗縮放（若支援）保持比例且不會重新觸發分析。
9. 深底亮字的對比，標題也要檢查，不只是數值。
10. 每個不直覺的控制項都有一句話的 tooltip 或 `?` 說明層。

## 8. JUCE 要點

- 控制項建立在 `juce::Slider` 上，用自訂的 `LookAndFeel_V4` 子類別；設定 `RotaryHorizontalVerticalDrag`、`setDoubleClickReturnValue(true, default)`、`setMouseDragSensitivity(180)`、`setVelocityModeParameters` 做微調、`TextBoxBelow` 搭配 `setNumDecimalPlacesToDisplay(1)`。
- 用 `AudioProcessorValueTreeState::SliderAttachment / ButtonAttachment / ComboBoxAttachment` 綁定；attachment 會處理 gesture 開始／結束，host 的自動化才錄得正確。
- 電表資料：音訊執行緒寫 `std::atomic<float>` peak；編輯器用 30 Hz 的 `Timer` 讀取，只重繪電表元件（`repaint(bounds)`），不重繪整個編輯器。
- 優先用向量繪圖（`Path`、`drawRoundedRectangle`）而非點陣圖，Retina 縮放就免費。
- WebView 編輯器拿來做原型可以；正式版用原生元件，避免 host 的 webview 版本漂移。

## 9. 網頁原型要點

- 用 `AudioContext.decodeAudioData` 解碼；所有重的 DSP 放在 `Worker`（用 transfer 傳 `Float32Array`），滑桿才不會卡；用細的進度條顯示進度。
- 所有要比較的路徑同時播放，各自經過 `GainNode → StereoPannerNode → AnalyserNode`，切 A/B 或 solo 時 sample 級同步、位置永不中斷。
- Master 鏈尾端放 `DynamicsCompressor` 當 brickwall（-1 dB、ratio 20、attack 1 ms），實驗才不會炸到使用者的監聽喇叭。
- 垂直推桿：把原生 `<input type=range>` 旋轉 -90° 放在固定高度的容器裡；用 CSS 變數畫軌道的填色。
- 匯出用 host 的下載能力；只允許特定副檔名時，把 WAV 打包成 zip。
